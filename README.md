# 🚀 JJSS v2.1 : 직업재활 전문가를 위한 지능형 업무 보조 시스템

![JJSS 로고 또는 스크린샷 이미지 넣을 자리](https://via.placeholder.com/800x400?text=JJSS+Job+Journey+Support+System)

> **JJSS(Job Journey Support System)**는 행정 업무의 부담을 덜어내고, 복지 현장 전문가들이 **'사람과 사람의 연결'**이라는 본연의 가치에 집중할 수 있도록 개발된 인공지능(AI) 기반 데스크톱 애플리케이션입니다. 번거로운 서류 작업은 AI에게 맡기고, 소중한 시간을 더 가치 있게 활용해 보세요!

---

## 💡 왜 JJSS를 사용해야 할까요? (주요 기능)

### 1. 🤖 AI 사례관리 타임라인 (워크플로우 통합)
* **스토리텔링형 연속 기록**: 단편적인 기록에서 벗어나, 초기 상담부터 사례회의, 평가서까지 AI가 이전 기록의 문맥을 기억하여 **하나의 일관된 이야기**처럼 연속해서 초안을 작성합니다.
* **시간의 마법**: 기존에 몇 시간이 걸리던 두꺼운 문서 작성 업무를 단 클릭 몇 번, **몇 분 만에 완성도 높은 초안으로 탈바꿈**시켜 줍니다.

### 2. 🛡️ 철저하고 안전한 개인정보 보안 (Auto-Masking)
* **로컬 가명 처리 기술**: 클라이언트의 소중한 정보를 AI 서버로 전송하기 전에 **프로그램 내부(사용자의 PC)에서 자동으로 이름, 연락처 등을 비식별화(예: 홍길동 → 홍*동)** 처리합니다. 
* **안심하고 쓰는 AI**: 작업이 끝나면 원래 이름으로 깜쪽같이 되돌려주어, 혹시 모를 정보 유출 사고를 원천 차단합니다. 

### 3. 🎨 클릭 한 번으로 끝나는 디자인 (AI 홍보 도구)
* **비전문가도 금손으로**: 복잡한 포토샵이나 디자인 툴 없이도, 직업재활 사업 홍보에 필요한 안내문이나 포스터 이미지를 마법처럼 생성해 줍니다. 

### 4. 📄 공문서 규격 즉시 출력 (Word 연동)
* **다운로드 즉시 보고 완료**: 화면에서 작성된 상담일지, 평가 계획서 등을 번거로운 복사/붙여넣기 없이 **Docx(워드) 파일 형태로 깔끔하게 변환하여 다운로드**합니다. 다운로드 후 바로 결재에 올리세요!

## ⚙️ 초보자도 할 수 있는 초간단 설치 및 사용법 (필독)

JJSS는 컴퓨터를 잘 모르는 분들도 쉽게 쓸 수 있도록 만들어졌습니다. 아래 3단계만 천천히 따라 해 주세요.

### 1️⃣ JJSS 프로그램 다운로드 및 설치
1. 우측(또는 하단)의 **[Releases]** 섹션에서 본인의 운영체제에 맞는 파일을 다운로드합니다.
   * 🪟 **[Windows 사용자]**: **`JJSS.Setup.2.1.exe`** 파일을 다운로드하고 더블클릭합니다.
     - ⚠️ *(중요)* "Windows의 PC 보호"라는 파란색 창이 뜰 수 있습니다. 당황하지 마시고 **[추가 정보]** 글씨를 누른 후 **[실행]** 버튼을 누르시면 정상적으로 설치가 진행됩니다.
   * 🍎 **[Mac M1/M2/M3 사용자]**: **`JJSS-1.0.0-arm64-mac.zip`** 파일을 바탕화면에 다운로드합니다.
     - 압축을 풀고 나오는 **`JJSS`** 앱을 꼭! **`응용 프로그램(Applications)`** 폴더로 끌어다 옮겨 주신 후 [Launchpad]에서 실행하세요.
     - ⚠️ *(중요)* "확인되지 않은 개발자가 배포했기 때문에..."라는 오류가 난다면 당황하지 마시고 **해당 JJSS 앱을 키보드의 [Control] 키를 누른 상태로 클래 클릭(또는 우클릭)** 하신 뒤 나오는 메뉴에서 **[열기]**를 누르시면 정상적으로 권한이 승인되어 열립니다.

### 2️⃣ 나만의 AI 열쇠(API 키) 발급받기 (완전 무료)
이 프로그램이 척척박사처럼 일하려면 **구글 Gemini의 두뇌**를 빌려와야 합니다. 이를 위해 열쇠(API 키)를 하나 받아야 합니다.
1. [🔗 구글 AI 스튜디오 홈페이지(클릭)](https://aistudio.google.com/app/apikey) 에 접속하여 구글 계정으로 로그인합니다.
2. 파란색 **[Create API key(API 키 만들기)]** 버튼을 누릅니다.
3. 영문과 숫자로 이루어진 **긴 암호 같은 텍스트**가 생성됩니다. 그 옆에 있는 **[Copy(복사)]** 버튼을 눌러 복사해 둡니다.
> 💸 **비용 걱정은 NO!** 개인 사용자는 이 열쇠를 **무료**로 넉넉하게 사용할 수 있습니다.

### 3️⃣ 프로그램에 열쇠 끼우기 (마지막 단계)
1. 바탕화면에 설치된 **JJSS** 프로그램을 실행합니다.
2. 화면 왼쪽 맨 밑에 톱니바퀴 모양의 **[설정]** 아이콘을 클릭합니다.
3. 방금 복사했던 긴 암호를 **[Gemini API Key]** 칸에 마우스 우클릭 -> **붙여넣기** 합니다.
4. **[저장]** 버튼을 누르고 프로그램 홈 화면으로 돌아가시면 끝! 이제 모든 마법 같은 기능들을 마음껏 사용해 보세요.

## ❓ 자주 묻는 질문 (FAQ)

**Q. 인터넷이 꼭 연결되어 있어야 하나요?**
> A. 네! AI가 두뇌(클라우드 서버)와 통신해야 하므로 **반드시 인터넷에 연결**되어 있어야 합니다.

**Q. API 키를 넣었는데 에러가 나요.**
> A. 키 목록을 복사하실 때 띄어쓰기나 공백이 들어갔을 수 있습니다. 복사한 텍스트 앞뒤로 쓸데없는 빈칸이 없는지 확인 후 다시 저장해 보세요.

**Q. Mac(애플 컴퓨터)을 사용하는데 설치가 되나요?**
> A. 네! 이제 **M1, M2, M3(Apple Silicon)** 칩셋이 탑재된 Mac 장비도 완벽하게 지원합니다! Releases 탭에서 Mac용 zip 파일을 받아주세요. (단, 오래된 인텔 Mac의 경우는 지원하지 않을 수 있습니다.)
