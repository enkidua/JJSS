# 🚀 JJSS : 지능형 직업재활 업무 보조 시스템

JJSS(Job Journey Support System)는 직업재활 현장의 전문가분들이 행정 업무를 AI의 도움을 받아 효율적으로 처리할 수 있도록 돕는 데스크톱 앱입니다.

## ✨ 주요 기능
1. **AI 사례관리 타임라인**: 상담일지 등 연속적인 흐름 관리.
2. **개인정보 자동 마스킹**: 보안을 위한 가명 처리 기능.
3. **AI 홍보 도구**: 포스터 및 이미지 제작 지원.

## 📥 설치 및 실행 방법 (가장 중요!)
1. 화면 오른쪽 **[Releases]** 섹션에서 가장 최신 버전의 `.exe` 파일을 다운로드합니다.
2. 다운로드한 파일을 실행합니다.
3. 왼쪽 하단 **[설정]** 메뉴에서 개인 Gemini API Key를 입력하면 즉시 사용 가능합니다.
