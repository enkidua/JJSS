# JJSS 3.0 — 직업재활 실무를 위한 AI 업무지원 프로그램

JJSS(Job Journey Support System)는 직업재활상담사와 장애인 고용·직업재활 실무자를 위한 Windows 데스크톱 프로그램입니다. 상담, 사례관리, 직업재활계획서, 직업평가, 직업훈련, 사업체·예산 관리와 AI 문서 초안 작성을 한 프로그램에서 할 수 있습니다.

- 현재 버전: **3.0.0**
- 지원 환경: **Windows 10/11 (64비트)**
- AI 제공업체: **Google Gemini, OpenAI, Anthropic Claude** 중 하나 이상(직접 발급한 API 키 사용)

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 사례관리 타임라인 | 초기 상담부터 사례회의, 직업재활계획서, 사후관리까지 이전 기록을 이어 받아 AI가 다음 문서의 초안을 만듭니다. |
| 직업재활계획서 | 기관 양식에 맞춘 계획서를 Word(DOCX)·PDF·PNG로 저장합니다. |
| 직업평가·직업훈련 | 평가 결과 정리와 종합소견서 초안, 훈련 계획·출석·진도 기록을 지원합니다. |
| 이용자·사업체·예산 | 이용자와 사업체 정보, 사업 예산과 지출 내역을 관리하고 지출품의서를 만듭니다. |
| AI 업무 도구 | 회의록 정리, 문서 검토, 영수증·문서 글자 인식(OCR), 홍보물 문구·이미지 등 반복 업무를 돕습니다. |
| 개인정보 가리기 | AI로 보내기 전에 이름·연락처·주민등록번호 같은 정보를 가명으로 바꾸는 기능이 있습니다. 모든 정보를 완벽하게 찾아내지는 못하므로, 민감한 내용은 보내기 전에 직접 한 번 더 확인해 주세요. |

## 설치 방법

1. [GitHub Releases](https://github.com/enkidua/JJSS/releases)에서 설치 파일을 내려받습니다.
   - 빌드한 설치 파일 이름은 `JJSS Setup 3.0.0.exe`입니다. GitHub에서는 공백이 점으로 바뀌어 `JJSS.Setup.3.0.0.exe`로 보입니다. 두 이름은 같은 파일입니다.
2. 내려받은 파일을 두 번 눌러 설치합니다. 설치 위치를 바꿀 수 있고, 바탕화면과 시작 메뉴에 바로가기가 만들어집니다.
3. **"Windows의 PC 보호"(SmartScreen) 파란 창이 뜨는 경우**
   - JJSS 설치 파일은 공인 코드서명 인증서로 서명되지 않았기 때문에 이 경고가 나올 수 있습니다.
   - 공식 Releases에서 받은 파일이 맞다면 **[추가 정보]**를 누른 뒤 **[실행]**을 누르면 설치가 계속됩니다.
   - 파일이 바뀌지 않았는지 확인하려면 PowerShell에서 아래 명령으로 나온 SHA-256 값이 Releases·홈페이지에 적힌 값과 같은지 비교합니다.

     ```powershell
     Get-FileHash "$env:USERPROFILE\Downloads\JJSS.Setup.3.0.0.exe" -Algorithm SHA256
     ```

4. 이전 버전을 쓰고 있었다면 **제거하지 말고** 그대로 새 버전을 설치하세요. 저장된 이용자·문서 데이터가 유지됩니다. 설치 전에 설정 화면에서 백업을 한 번 만들어 두면 더 안전합니다.

> 설치 중 "JJSS가 실행 중입니다"라는 창이 뜨면 JJSS를 종료한 뒤 [다시 시도]를 누르세요. JJSS 창이 보이지 않는데도 계속 뜬다면 같은 컴퓨터의 다른 Windows 계정에서 JJSS가 실행 중일 수 있습니다. 이때는 컴퓨터를 다시 시작한 뒤 설치하세요.

Mac용 설치 파일은 3.0 버전에서 제공하지 않습니다.

## AI 연결하기 (API 키 등록)

JJSS의 AI 기능을 쓰려면 아래 제공업체 중 **하나 이상**에서 API 키를 발급받아 등록해야 합니다.

| 제공업체 | 키 발급 페이지 | 비용 |
|---|---|---|
| Google Gemini | [Google AI Studio](https://aistudio.google.com/app/apikey) | 무료 사용 한도(Free tier)가 있어 가볍게 시작할 수 있습니다. 한도를 넘기거나 유료 요금제를 쓰면 사용량만큼 요금이 나옵니다. |
| OpenAI | [OpenAI API keys](https://platform.openai.com/api-keys) | 사용량만큼 요금이 나옵니다(결제 수단 또는 선불 크레딧 필요). |
| Anthropic Claude | [Claude API keys](https://platform.claude.com/settings/keys) | 사용량만큼 요금이 나옵니다(결제 수단 또는 선불 크레딧 필요). |

요금과 무료 한도는 제공업체가 수시로 바꿉니다. 정확한 금액은 각 제공업체의 요금 안내를 확인해 주세요.

**등록 순서**

1. 위 페이지에서 로그인한 뒤 API 키를 만들고 **[복사]**합니다.
2. JJSS를 실행하고 왼쪽 메뉴의 **[설정]**을 누릅니다.
3. 해당 제공업체 칸에 키를 붙여넣습니다. 앞뒤에 빈칸이나 줄바꿈이 섞이지 않았는지 확인하세요.
4. **[연결 확인]**으로 키가 올바른지 확인합니다.

API 키는 이 컴퓨터 안에 암호화해 보관하며, 백업 파일에는 포함되지 않습니다.

## 데이터는 어디에 저장되나요?

- **이용자·상담·사례 문서 등 입력한 자료**: 이 컴퓨터의 JJSS 앱 데이터 폴더에 저장됩니다. 다른 컴퓨터나 다른 Windows 계정과 자동으로 공유되지 않습니다.
- **저장한 파일(DOCX·PDF·PNG·CSV·백업)**: 기본 위치는 `문서\JJSS`입니다. 저장할 때마다 원하는 폴더를 고를 수 있고, 마지막으로 고른 폴더를 기억합니다.
  - 이전 버전에서 `D:\JJSS`에 파일을 저장해 쓰던 경우에는 그 위치를 그대로 계속 사용합니다.
  - 저장 위치가 USB·외장 드라이브라서 연결되어 있지 않으면, 다른 곳에 몰래 저장하지 않고 안내 창을 띄웁니다. 드라이브를 연결하고 [다시 확인]을 누르거나, [문서 폴더로 변경]을 고를 수 있습니다.
- **AI 기능을 사용할 때**: 입력한 내용(가명 처리된 내용 포함)이 선택한 AI 제공업체의 서버로 전송됩니다. 각 제공업체의 개인정보·데이터 처리 방침을 확인해 주세요.
- 정기적으로 **설정 → 파일·백업**에서 백업 파일을 만들어 안전한 곳에 보관하세요.

## 자주 묻는 질문

**Q. 인터넷이 꼭 필요한가요?**
A. AI 기능(문서 초안 작성, 글자 인식 등)은 인터넷이 필요합니다. 이용자 관리, 저장된 문서 보기 등은 인터넷 없이도 쓸 수 있습니다.

**Q. API 키를 넣었는데 오류가 나요.**
A. 복사할 때 앞뒤 빈칸이나 줄바꿈이 들어갔는지 확인하고 다시 붙여넣어 보세요. 유료 제공업체(OpenAI·Claude)는 결제 수단이나 크레딧이 없으면 키가 있어도 오류가 납니다.

**Q. JJSS 아이콘을 두 번 눌렀더니 창이 하나만 떠요.**
A. 데이터 충돌을 막기 위해 JJSS는 한 번에 하나만 실행됩니다. 이미 실행 중이면 기존 창이 앞으로 나옵니다.

**Q. 저장이 안 되고 "다른 프로그램에서 열려 있습니다"라고 나와요.**
A. 같은 이름의 파일이 한글·Word 등에서 열려 있습니다. 그 프로그램에서 파일을 닫은 뒤 다시 저장하세요.

## 개발자용

```powershell
npm install
npm run dev            # 브라우저 개발 모드(http://localhost:5173)
npm run electron:dev   # 빌드 후 Electron 앱으로 실행
npm run test:all       # 자동 테스트와 릴리즈 사전검사
npm run electron:build # Windows 설치 파일 생성(미서명) → release\JJSS Setup <버전>.exe
```

- 서명 빌드와 미서명 빌드의 차이, 배포 전 확인 항목은 [docs/WINDOWS_RELEASE_CHECKLIST.md](docs/WINDOWS_RELEASE_CHECKLIST.md)와 [docs/WINDOWS_INTERNAL_SIGNING.md](docs/WINDOWS_INTERNAL_SIGNING.md)를 참고하세요.
- 자동 업데이트 기능은 없습니다. 새 버전은 Releases에서 내려받아 기존 설치 위에 설치합니다.
