# 2026-05-08 직업훈련 메뉴/라우트 복구 기록

## 작업 목표

v2.2 핵심 기능인 직업훈련 화면을 다시 앱 메뉴와 라우트에 연결했습니다.

인포메이트, 소통 공간/커뮤니티, 인트라넷은 다시 연결하지 않았습니다.

## 복구한 메뉴/라우트

### 직업훈련

- 라우트: `/training`
- 메뉴명: `직업훈련`
- 아이콘: `GraduationCap`
- 컴포넌트: `src/pages/WorkTraining.tsx`

## 최종 메뉴 구조

1. 서비스 소개
2. 이용자 및 사업체 관리
3. 직업평가
4. 직업훈련
5. 고용지원/사례관리 및 매칭
6. 예산 관리
7. 업무 지원 도구
8. 설정

## 계속 제거 상태로 유지한 메뉴

- 인포메이트
- 소통 공간/커뮤니티
- 인트라넷

- `src/components/Navbar.tsx`

`npm run build` 통과.

## 남은 문제

이번 작업 기준으로 메뉴/라우트 연결 문제는 없습니다.

다만 직업훈련 내부 기능의 세부 동작 검증은 별도 단계에서 확인해야 합니다.
