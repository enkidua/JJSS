# 지원고용 기록 편의 보완

## 근거

사용자가 제공한 2026년 중증장애인 지원고용사업 업무 매뉴얼의 훈련생 관리·휴게시간·직무지도원 수당 및 붙임 16·18·19를 로컬에서 추출해 대조했다. 원문·이용자 데이터를 외부 AI로 보내지 않았다. 추출 텍스트는 표 배치를 완전히 보존하지 않으므로 공식 서식 재현은 변경하지 않았다.

## 변경

- 기존 표를 유지하고 ‘하루 기록 도우미’에 날짜별 큰 입력창 추가. 같은 수행과제·측정시간별 수행정도·지도사항을 편집한다.
- 오늘까지 비어 있는 기본 항목 집계와 미작성 날짜 이동. 미래 일정은 예정으로 표시. 작성 여부는 출석·수당 적격 판정이 아니다.
- 관찰 → 실시한 지원 → 반응·변화 → 다음 지원의 빈 틀을 기존 기록 끝에만 추가. 자동 사실 생성 없음. 중복·1,000자 초과 방지 및 원문 보존.
- 매뉴얼의 정확성·속도·측정시간, 기본규칙·대인관계, 지속 지도 후 변화 안내.
- 4~8시간 훈련, 휴식시간, 현장훈련 야간·휴일 금지, 출석시간 50% 미만 결석, 출퇴근·휴식지도 양쪽 기록 확인 안내.
- 이전 행 복사가 기존 입력을 덮어쓸 때 확인. 취소 시 입력 보존.

## 유지와 한계

이번 도우미 작업은 DB_VERSION·저장소·JSON 구조·수당 계산·문서 생성·API 호출을 변경하지 않는다. 기존 회차 저장과 미저장 보호를 사용한다.
예정시간과 실제 출석시간이 분리되어 있지 않아 50% 미만 규칙을 시간차로 추측하지 않는다. 담당자가 실제 시간을 확인해 출결을 변경해야 한다.
휴식지도는 기존 지도사항에 기록하고 출근부와 대조하도록 안내했다. 별도 공식 휴식지도 체크 칸이나 수당 자동 판정은 추가하지 않았다.
기존 일괄 출석·기본 출석값은 유지하고 실제 출석 확인 안내를 추가했다.

## 검증

- 타입 검사 및 test:all 통과. 기존 지원고용 계산·직렬화·7종 DOCX, 파일 저장, API 안전성, 암호화 테스트 포함.
- 기록 틀 보존·중복·초과·결석 사유·빈 항목 단위 테스트 추가.
- 실제 앱 회차 브라우저 흐름에서 입력 동기화, 날짜 유지, 기록 보존, 중복·길이 제한, 복사 취소 통과.
- Vite 빌드 및 배포 번들 검사 통과. 기존 청크 크기·Browserslist 경고는 남음.
- 설치본 실기기·실제 프린터 출력은 미검증. 설치파일 재생성·커밋·푸시는 하지 않음.
