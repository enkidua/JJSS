## 데이터 보존
- AI 보완 실패 시 기존 textarea/editor 내용은 이전 값으로 되돌려 유지한다.
- 보완 실행 전 확인창을 띄워 바로 덮어쓰지 않도록 했다.
- 저장된 사례관리/직업훈련/직업평가 데이터 구조는 변경하지 않았다.

## 검증
- `npm run build` 통과
- Vite 경고: 번들 청크가 500kB 이상이라는 기존 성능 경고가 남아 있다.

## 남은 위험 요소
- 매칭 의견 저장은 DB 마이그레이션을 피하기 위해 `localStorage`를 사용했다. 향후 장기 보존/백업 포함이 필요하면 기존 문서 저장소와 연결하는 후속 작업이 필요하다.
- 직업훈련 파일에는 과거 구현 흔적이 일부 남아 있어, 후속 정리 때 사용 중인 컴포넌트와 미사용 컴포넌트를 나누어 정리하는 것이 좋다.
- “면접일지” 전용 화면은 현재 명확히 연결된 구현을 찾지 못해 이번 단계에서는 별도 적용하지 않았다.
