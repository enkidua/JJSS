# JJSS 향후 개선 제안 보고서

작성일: 2026-08-12

## 보고서 범위

이 문서는 장기적으로 검토할 개선사항과 기존 제안 중 이번 작업에서 1차 구현된 항목의 제한을 구분해 기록한다. 남은 제안은 DB 구조·저장 흐름·UI·배포 설정에 반영하지 않았다.

## 2026-08-14 1차 구현 완료

| 항목 | 구현 범위 | 남은 제한 |
|---|---|---|

## 단계별 추진 권장안

1. 먼저 출력 전 비식별화 모드의 대상 필드와 원본 보존 정책을 설계한다.
2. 다음으로 PDF 반복 머리글·프린터별 페이지 나눔과 페이지별 PNG를 검증한다.
3. 이후 현재 단일 DOCX 양식을 기반으로 양식 템플릿 업로드·버전 관리를 별도 설계한다.
4. 전자서명은 인증·권한·감사기록 정책이 정해진 뒤 별도 프로젝트로 추진한다.
5. lazy loading은 기능 안정화 이후 번들 분석 결과를 기준으로 라우트별로 점진 적용한다.

## 이번 작업에서 제외했음을 재확인하는 항목

- 전자서명 또는 결재 승인 워크플로우
- 새 IndexedDB store와 DB 버전 변경
- 양식 템플릿 업로드·저장·버전 관리
- 비식별화 출력 모드
- PDF 반복 머리글 및 프린터별 고급 페이지 분할
- 페이지별 PNG/ZIP 내보내기
- 이용자명 포함 파일명 옵션
- 전체 개인정보 필드 암호화 확대 및 기존 데이터 마이그레이션
- 백업 복원 장애 주입 자동 테스트
- 라우트 lazy loading과 번들 구조 변경
